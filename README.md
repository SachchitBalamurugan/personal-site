# sachchit-site

My personal website: painted skies, a scroll-driven desktop that walks through my featured projects, and the rest of what I've built.

Live: https://sachchit-site.vercel.app

Built with Vite, React, TypeScript and GSAP (ScrollTrigger). The clouds and skies are drawn in SVG and CSS, so there are no image assets for them. Content lives in `src/data/`, and the project screenshots are in `public/work/`.

```bash
npm install
npm run dev
```
